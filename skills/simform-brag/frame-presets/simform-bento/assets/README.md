# Brand assets

- `simform-logo.svg` — Simform's own logo, fetched from `simform.com` and vendored here for the
  `logo-lockup` component (full presence on Hero Bento Cover / Sign-off Bento, watermark
  elsewhere) and the opt-in `--simform-outro` card.

Unlike the CC0 SFX (Kenney) and licensed music (ende.app) bundled elsewhere in this skill, this
is Simform's own trademark/brand asset, not open-licensed third-party media. It's vendored here
only for generating Simform's own collateral — governed by Simform's internal brand guidelines,
not this repo's MIT code license, and shouldn't be assumed freely reusable outside
Simform-controlled distributions of this plugin.
